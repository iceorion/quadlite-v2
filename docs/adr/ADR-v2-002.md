## 决策

### D1（沿用）B1 只交付 L0 纯函数层，不改已验证算法的语义

- 交付 13 个 `src/QuadLite.Core/*.cs`：`PathKey` / `SafeWalk` / `ColumnLayout` / `ViewSpec` / `CellMetrics` / `MenuModel` / `SafetyGuard` / `OpPlan` / `OpRecord` / `Selection` / `StateModel` / `ErrorModel` / `NaturalSort`。
- `design-v2.md` §3 把「借重构改名或重写已验证的纯函数算法（自然排序、列宽计算、路径规范化、危险判级）」列为非目标。公开仓不导入任何既有私有源码，因此代码是重新落地的，但**行为契约沿用**：自然排序的数字按数值与前导零规则、列宽 `Σ = 行宽 − 12` 与名称列保底 120、路径规范化覆盖长路径 / UNC / `..` 越界 / 设备命名空间 / 引号空白、危险判级只在 `SafetyGuard` 一处且矩阵逐格可测。判据写成 C# runner 的断言，不借重构改口径。
- `Core` 零 I/O：路径处理全部是字符串运算，不出现 `System.IO`；由 `check-boundaries` 的 B-01 / B-02 与 `check-core-specs` 双重静态检查。

### D2（新增）本机不能执行 C# 编译器，算法正确性由 CI 远端实跑

- 本机安全策略禁止直接调用系统 C# 编译器，也未确认 net48 的 WPF 构建工具链；因此**本机不编译、不运行 C#**，如实标「未验证」，不把「静态检查没报错」当成「代码能跑」。
- CI 的 `csharp-runner` 步骤在 Windows runner 上用系统自带的 .NET Framework 编译器，以 `/langversion:5 /codepage:65001` 把 13 个 Core 文件与 `tests/QuadLite.Tests` 的 runner 编成单个 exe 并运行；`verdict: GREEN` 且退出码 0 才算过。`/langversion:5` 同时把 DD-01 的 C# 5 语法子集变成机器可判的约束。
- 该步骤只编译 L0 与零依赖 runner（只引用系统程序集），**不等于** WPF 应用可构建、也不等于单文件出包可用；`build.ps1 -SingleFile` 与 exe 形态 `--selftest` 仍标「未验证」。

### D3（新增）门卡按证据等级分三层，不互相冒充

| 层 | 覆盖范围 | 判据 | 证据等级 |
|---|---|---|---|
| Python 静态契约 | 类型齐备、C# 5 语法子集、枚举完备性、runner 门卡组注册、Core 零 I/O | `tools/check_core_specs.py` 绿；4 类负向对照变红 | 本机实测 |
| C# 算法 runner | 路径规范化、SafeWalk 四道边界、列宽恒等式、七档视图、自然排序、危险矩阵逐格、状态 / 错误模型、结构化 `OpRecord`、筛后选中集 | 14 组逐行 `ok=True`，末行 `verdict: GREEN`，退出码 = 红条数 | CI 远端实测（本机未验证） |
| 发布线 / 人工 | 同手感、高 DPI 四档、运行期零写入三段取证、B5 的 verb 实测、单文件出包 | 见 `docs/negative-controls.md` | 未验证 |

### D4（沿用）账本 `head_sha` 用回填提交写入

- 沿用 `ADR-v2-001` D4：功能提交先落地，账本行在紧随其后的回填提交中写入该提交的 SHA；回填提交只改账本与状态字段，不产生新批次行。
- B0 已验证此规则可用；B1 沿用，不引入自包含 SHA 的花招。

### D5（沿用）O-01 / O-05 / O-06 仍按 `ADR-v2-001` D3 的默认值执行

- B1 不涉及 shell 互操作、布局档位与筛选开关的实现，三项默认值不变；O-05 的 3 窗格与 O-06 的首版范围留给 B3 / B4。

## 负向对照

B1 新增 4 类静态负向对照，均由 `tools/run_tests.py` 在临时副本里实测「变红 → 恢复 → 变绿」：删掉一个 L0 类型文件、删掉 runner 的一个门卡组、注入 C# 6 插值语法、给 `ErrorClass` 加一个未同步规格表的枚举值。C# runner 内部的算法断言本身是正样本；它们的「改坏必红」由 CI 编译运行该 runner 来体现（改断言或改实现会让 `verdict: RED` 且退出码非 0）。明细见 `docs/negative-controls.md`。

## 影响与可逆性

- D2 可逆：一旦本机具备可执行的 C# 编译器与 net48 工具链，可把 `csharp-runner` 的编译命令原样搬到本地，本机证据等级由「未验证」升为「实测」；门卡与判据不变。
- D1 不引入第三方依赖、不改变产品运行时形态；`src/` 的 13 个文件全部是纯函数，B2 起在其上叠 L1 编排与 L3 适配器。
- 本 ADR 不含既有私有资产、内部路径或环境信息。
