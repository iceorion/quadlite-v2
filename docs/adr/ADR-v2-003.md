| 项 | 内容 |
|---|---|
| 编号 | `ADR-v2-003` |
| 日期 | 2026-11-05 |
| 状态 | 生效 |
| 关联 | `design-v2.md` v1.3 §1.2 / §2.1 FR-01、FR-07、FR-08 / §3 / §4.3 DD-07、DD-09 / §5.8 / §7.1、§7.2 / §8.1 B3 / §8.4 M1 / §11 O-05 / 附录 C；`ADR-v2-001` D3；`ADR-v2-002` D5；`docs/negative-controls.md` |

## 决策

### D1（新增）用一棵二叉分割树表达布局，不再用四档枚举作为状态

- `LayoutSpec` = 二叉分割树：内部节点持**根节点方向** `H`（横线贯穿 + 上 / 下排各一条竖支线）或 `V`（竖线贯穿 + 左 / 右列各一条横支线），以及一个比例 `r`；叶子是 `PaneId`。两种方向互为转置，不是两套实现。
- `r=0` 前侧折叠、`r=1` 后侧折叠、`0<r<1` 两侧都在；可见性只由树与比例推导，**不另存可见性布尔**（沿用已验证的比例唯一真相口径）。
- 每条分割线可拖到**任意比例**，双击按折前比例恢复，拖到 24px 阈值吸附折叠，折叠线留在原地变色作折返抓手。用户拖出来的布局跨会话保持，不受四档限制。
- 1 / 2 / 3 / 4 保留为**四组命名预设常量**（含标准比例与根方向），只作一键复位与快捷键入口；它们不是合法状态集合，也不阻止用户把布局停在任意中间比例。保留预设的理由是自定义布局必须有复位锚点，否则拖乱之后回不到标准形态；这是可用性要求，不是模式限制。

### D2（修订）O-05 作废，DD-07 修订，新增 DD-09

- `ADR-v2-001` D3 与 `ADR-v2-002` D5 中关于 **O-05「保留 3 窗格」** 的部分作废：3 窗格现在只是「`V` 根 + 折掉一条支线」的任意组合之一，原「保留 / 砍掉」的二选一被消解。O-01 / O-06 不受影响，仍按各自默认值执行。
- DD-07 的「沿用已验证行为契约」清单去掉「1/2/3/4 布局」，保留分隔条的比例折叠、24px 吸附、折前恢复、相对均分偏移持久化，以及其余纯函数算法口径。布局几何属于新设计，不属于「沿用」。
- 新增 DD-09，把分割树、两种根方向、四组预设、固定宿主绝对定位写成设计决策。

### D3（新增）树形状仍受约束，约束的是形状而不是档位

| 约束 | 值 | 理由 |
|---|---|---|
| 深度 | ≤ 2 | 只允许「一条贯穿线 + 两条支线」，覆盖两种根方向的全部折叠组合；更深会出现 L 形与嵌套不对称布局，命中、拖放、焦点与刷新语义都要另立规格 |
| 叶子数 | ≤ 4 | `PaneState` 最多 4 份，`ActivePaneId`、跨窗格拖放、撤销栈、`FsWatchService` 广播、`MenuTarget` 的 PaneId 都按最多 4 个建模 |
| 根方向 | 仅 `H` / `V` | 两种贯穿拓扑互为转置，是同一套递归布局的两个取值；不开放任意角度或非矩形分割 |

- 这不是把用户限制回四种模式：根方向 2 种 × 每条线任意比例 × 任意折叠组合，状态空间是连续的。超过 4 个窗格、深度 > 2 的树、非矩形分割列为 §3 非目标，后续可另立 ADR 放开，树结构本身不需要重写。
- 不加这条约束会让 3 窗格出现四种朝向、4 窗格出现错开 / 三并排等组合，`layout-*` 与人工验收的组合数不可控。

### D4（新增）四个 PaneView 常驻同一宿主，禁止换父容器

- 分割树一次递归算出 ≤ 4 个矩形；四个 `PaneView` 永远挂在同一个宿主上，由自定义 Panel 绝对定位。拖动只重算矩形，切换根方向也只重算矩形，**不重建控件、不换父容器**。
- 理由：既有实现里切换贯穿方向需要把某个窗格从子网格搬到外层网格，控件离树会让 `ScrollViewer` 归零，只能异步补偿滚动位置。固定宿主从结构上消掉这一类状态丢失，而不是继续修补。
- 代价是自己处理最小尺寸、高 DPI、命中区与尺寸变化重排；这些由 `split-*` 门卡与 `CONTRIBUTING.md` 的人工项承担，不靠「没报错」判定。

### D5（修订）门卡从「四档槽位」改为「任意树不变量」

- `layout-*`：矩形两两不重叠且面积和等于容器面积、`r=0/1` 不产生零面积叶子、`PaneId` 稳定、连线数等于内部节点数、四组预设可复现、根方向 `H/V` 两拓扑、五档窗口钉点。
- `split-*`：任意比例拖动、折叠 / 吸附 / 折前恢复、连线数、状态不重建、比例持久化。
- 负向对照示例由「把 3 窗格落位改成 4 窗格」改为「让分割树产生重叠矩形」与「切根方向时换父容器 / PaneId 漂移」。
- **门卡组名不变**（`layout-*` / `split-*`），因此附录 C 追踪矩阵与 `check-trace` 的四方一致关系不受影响；B3 的门卡条数沿用原表，只改判据内容。

### D6（沿用）证据分层与落地时机

- 沿用 `ADR-v2-002` D3 的三层证据：本机静态契约 / CI 编译实跑 / 发布线人工项互不冒充。本 ADR 只改规格与文档，**没有任何可运行的布局实现**，`layout-*` / `split-*` 的全部判据在 B3 之前一律标「未验证」。
- 时机：v2 的 B1 只交付了 13 个 L0 纯函数类型，其中没有布局类型；布局按 §8.1 归 B3，B2 尚未开工。此刻改规格只需改文档并重跑 `check-trace`，若等 B3 写完再改，要连带改 UI 代码与十几条门卡。

## 负向对照

B3 生效后按不变量覆盖，登记在 `docs/negative-controls.md`（当前均未跑，标「未验证」）：

| 不变量 | 破坏方式 | 应变红的门卡 |
|---|---|---|
| 矩形不重叠且面积和守恒 | 让递归布局产出重叠矩形或丢面积 | `layout-*` |
| 折叠不产生零面积叶 | `r=0/1` 仍给被折侧分配面积 | `layout-*` |
| PaneId 稳定 / 不换父容器 | 切根方向时重建 `PaneView` 父容器或重排 PaneId | `layout-*` `split-*` |
| 连线数 = 内部节点数 | 折叠后仍画出已折掉的线 | `split-*` |
| 四组预设可复现 | 改预设的比例或根方向 | `layout-*` |
| 比例持久化与坏值归一 | 注入越界比例 / 未来 `schemaVersion` | `session-*` `split-*` |
| 活动窗格回落与拖放命中 | 折叠当前活动窗格后快捷键打空、或按档位而非矩形命中拖放目标 | `layout-*` `keys-*` |

## 影响与可逆性

- 可逆：若自定义布局在 B3 实测不可控，一条新 ADR 即可把状态收回到命名预设；树结构、比例数学与固定宿主仍可保留，不需要删代码。
- 本次不改 B0 / B1 的任何源码、不改 CI 配置、不改门卡组名；规格、ADR、README、负向对照登记与历史 ADR 的状态标注同步即可。
- 公开仓不导入任何既有私有源码；分割树的比例折叠、吸附、折前恢复与相对均分偏移持久化沿用已验证的行为契约，不借重构改口径。
- 本 ADR 不含内部路径、环境信息或私有资产。
