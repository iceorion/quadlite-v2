## 决策

### D1（拍板）布局保持 v1.2 四档，规格一字不改

用户在本批开工前明确拍板：**保持 v1.2 的 1/2/3/4 四档布局，不采纳自定义二叉分割树方案，继续按 B6 推进规格批次**。此前 `e23f8d6` → `d24bb44` 撤回的改版与 `ADR-v2-003` 空号保持历史原状，不翻案、不补写。`design-v2.md` 仍是 **v1.2**，FR-01 / §5.8 / §8.1 / 附录 C 一个字未改，O-05「保留 3 窗格」继续按默认执行。

`check_shell_specs.py` / `check_list_specs.py` / `check_menu_specs.py` 的「规格与实现一致」门卡继续生效：它们守的是规格不被擅自改动，不因用户已拍板而放松。本批新增同类门卡 `check_icon_specs.py` 第 9 项，只核对规格仍为 v1.2 且 B6 判据声明未改。

B6 只关心单窗格内的图标档位、行集渲染与缓存键，**不读窗格数量、不读落位模型**；`ADR-v2-005` D7 划定的替换边界在本批不触发。

### D3（沿用 DD-07）复用已验证的 L0，不重复定义

B1 / B4 已交付并验证的骨架直接复用，B6 只补齐 §5.11 里尚未可判定的规则：

- `ViewSpecs`（七档视图的 16 / 48 / 96 / 256 图标像素）→ `IconChannelRules.ForView` 直接读取，不再列第二份档位表；
- `CellMetrics.VisibleSpan` / `SpanUnit`（Items / Pixels 单位不可混用）→ `IconChannelRules.UnitSafe` / `MixedUnitRejected`；

- `NavRules` / `EnumBatchRules` 的 generation 迟到丢弃 → `ThumbQueueRules.ShouldApplyResult`，与 `ADR-v2-005` D7 的替换边界无关；
- `ToggleRules.RequiresReenumeration(DisplayToggle.Thumbnail)` → `ThumbToggleRules.NoReenumOnThumbToggle`。

### D6（偏差，如实登记）§8.1 B6 未交付完的部分

- **真实图标与缩略图渲染未实现**：四级通道、exe 两段式、盘符逐像素比对、WIC 解码、`IShellItemImageFactory` 调用、EXIF 像素变换、可见优先队列的后台 worker、LRU 介质、视频 8 秒看门狗均只有纯函数判据，没有绑定代码。原因是 B6 沿用 B1–B5 的证据分层，且 `QuadLite.Probe` 项目与真实 WPF 控件尚未建立。
- **三段取证未做**：`ThumbWriteRules.EvidenceZones()` 只给出「注册表 / 应用目录 / 系统缓存」三个观察区，运行期零写入取证属发布线 H3，标「未验证」。`docs/negative-controls.md` 的写入例外清单仍恰好一条（thumbcache），由 `check-boundaries` INV-06 与 `check_icon_specs` 双重核对。
- **缓存落盘未实现**：`data\` 侧没有缩略图缓存文件；`ThumbState` 的 `CacheEntries` / `CacheBytes` 是不可变状态内核字段，不是磁盘事实。
- **`FakeShellExtension` 仍暂驻 Tests 层**（`ADR-v2-007` D6 遗留），B6 不建 Probe 项目、不让产品程序集引用测试替身。
- **本批不等于「应用可启动」**，也不宣称「图标与缩略图已可用」。§8.4「每批结束应用必须可启动」与 M1 判据仍按 `ADR-v2-002` 的证据分层记为未达成。B6 属 M2 体验完备批次，但真实 WPF 窗口、列表控件、原生菜单 COM 宿主、`IFileOperation` 搬运与构建出包均未接入。

### D7（规格解读，写清口径）§5.11 三处含糊表述的落地方式

- 「WIC 内置解码器全集 14 种，含 `.ts` 的 1 MB 尺寸下限」：白名单按 **14 个扩展名**落地（BMP / GIF / ICO / JPEG / PNG / TIFF / DDS / JPEG XR 家族及其别名），`.ts` 归视频容器侧，另有独立的 1 MB 尺寸下限判据；两处共用同一个 `TsMinBytes`，不产生第二套门槛。
- 「缓存键四段并含类型隔离 `i|` / `v|`」：四段为 kind / path / size / stamp，类型段在最前且只能是 `i|` 或 `v|`，图片与视频键天然不互相覆盖。
- 「视频缩略图写系统缓存是唯一显式写入例外」：`WriteAllowed` 同时要求 zone 为系统缓存且动机与系统文件管理器相同；缺一即不允许，且设置区与应用目录区恒为 0。

## 理由

1. 用户拍板「保持四档、继续 B6」，原计划即 `design-v2.md` §8.1 的 B6 定义；B6 与布局落位无交集，不因拍板返工。
2. §5.11 的 26 项常量与不变量全部可在零 I/O 条件下判定；把本机无法验证的 WIC / Shell 绑定混进来只会稀释证据，与 B0–B5 的纪律一致。
3. B1 / B4 已经把图标档位、可见区间、作业状态机与缩略图开关的 L0 骨架验证过；重复定义会违反 DD-07「不借重构改名或重写已验证算法」。
4. 把「唯一写入例外」做成源码常量 + 文档清单双门卡，是对 NFR-02「`data\` 之外零写入」最直接、可自动回归的兜底。
